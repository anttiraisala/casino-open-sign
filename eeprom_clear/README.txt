EEPROM CLEAR TOOL - sets every byte of the Arduino Mega's EEPROM to 0xFF
========================================================================

Purpose
-------
The menu settings of the casino sign (casino_open_sign_v2) are saved in the Mega's EEPROM. Uploading a sketch over USB does NOT
clear the EEPROM, so the saved settings survive an upload of a new version of the sign program (if the menu layout of a new
version has changed, the sign notices it by the layout tag and starts with the defaults by itself). When you want a really
empty EEPROM, upload this tool once. Afterwards upload the sign program again: it finds no saved settings and starts with
the default values of the menu. (The menu item "Restore defaults" of the sign does the same for the values that the menu
knows; this tool clears every byte.)

What it does
------------
At start-up, once: counts the EEPROM bytes that are not 0xFF, writes 0xFF to every byte (EEPROM.update(), so only the bytes
that differ are really written and the EEPROM wears as little as possible), reads everything back and checks that all bytes
are 0xFF. Then it only blinks the LED and prints a status line every second. It never writes the EEPROM again until the
next power-up or reset, so replace it with the sign program when you are done.

Wiring
------
None. The tool uses no pin. Connect the USB cable between the PC and the Mega (see wiring-diagram.svg / .pdf). The sign
hardware may stay connected.

How to use
----------
  1. Open eeprom_clear/sketch.ino in the Arduino IDE, select the Arduino Mega 2560 and upload it.
  2. Open the Serial Monitor at 115200 baud (the speed is also stated at the top of sketch.ino and printed at start-up).
  3. You see, once:
         EEPROM clear tool: every EEPROM byte is set to 0xFF once, now.
         Serial speed 115200 baud; a DBG line is printed every second.
         EEPROM size 4096 bytes, 37 of them were not 0xFF.
         EEPROM cleared: all bytes are 0xFF. Upload the sign program now.
     (4096 bytes is the size of the Mega's EEPROM; the number of used bytes depends on what was saved.) If the Serial Monitor
     was opened after the upload, press the reset button of the Mega to see the text again. The EEPROM is cleared again then,
     which does no harm.
  4. Sign of life: the LED on pin 13 blinks slowly (every 500 ms) when the EEPROM is clear, FAST (every 100 ms) if some byte
     could not be cleared. Once per second the Serial Monitor gets
         DBG up=<s> size=<bytes> before=<bytes that were not 0xFF> bad=<bytes still not 0xFF> state=<OK|FAIL> beats=<n>
  5. Upload the sign program (casino_open_sign_v2/sketch.ino) again. It starts with the default menu values.

If the message says "EEPROM clear FAILED" and the LED blinks fast, some byte of the EEPROM cannot be written any more (worn out
or a faulty chip); try once more with the reset button, and if it stays, the Mega's EEPROM is damaged.
